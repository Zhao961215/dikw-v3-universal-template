# DIKW 记忆系统 v3（通用部署模板）

> **5 分钟内让任意 Hermes Agent 拥有完整的 DIKW 记忆系统 v3 能力**
>
> 11 步信息流：指令→Agent→大脑→图书馆 5 层→工具决策→处理→反馈→迭代

## 快速开始

```bash
# 1. 复制到工作区
cp 02-SOUL.md ~/.hermes/SOUL.md
cp 03-AGENTS.md ~/.hermes/AGENTS.md
mkdir -p ~/.hermes/data/knowledge/vault/00-系统文档/
cp 01-记忆系统使用指南.md ~/.hermes/data/knowledge/vault/00-系统文档/

# 2. 替换占位符
#    {主人称呼} {沟通平台} {工作区路径} {系统代码目录} {业务模块} {平台名} {用户名}

# 3. 启动
hermes --tui
```

## 4 个文件

- **00-README.md** — 总览 + 快速开始 + 部署到新机器步骤
- **01-记忆系统使用指南.md** — DIKW 4 层 + 11 步信息流
- **02-SOUL.md** — Agent 行为规则 + 信息检索流水线
- **03-AGENTS.md** — 工作区目录规范

## 11 步信息流（v3 唯一权威）

```
1. 指令
2. Agent
3. 大脑（Holographic fact_store）
4. 图书馆 5 层（不跳步）：
   4.1 踩坑 → 4.2 知识库 → 4.3 近期对话 → 4.4 缓存点 → 4.5 网络搜索
5. 工具决策（5 步全自动）
6. 处理数据
7. 结果/反馈
8. 迭代方法论
```

**强约束**：听到"信息流/检索/查找"类指令 → 严格按 1→2→3→4.1→4.2→4.3→4.4→4.5→5→6→7→8 走，**不跳步**。

## 占位符

| 占位符 | 含义 |
|---|---|
| `{主人称呼}` | 你希望 Agent 怎么称呼你 |
| `{沟通平台}` | 飞书 / Telegram / Discord |
| `{工作区路径}` | 默认 `~/.hermes/` |
| `{系统代码目录}` | 默认 `hermes-agent/` |
| `{业务模块}` | investment / novel / office |
| `{平台名}` | feishu / telegram / discord |
| `{用户名}` | 当前登录用户名 |
